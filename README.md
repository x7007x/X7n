# موسوعة علم المصريات

تطبيق Android تعليمي باللغة العربية، مبني بواجهة Jetpack Compose، يقدّم موسوعة مختصرة عن ملوك مصر القديمة والمتاحف والمقابر والمجموعات الهرمية والآثار والمواقع الأثرية، مع البحث والتصفية والمفضلة ومشاركة العناصر والاختبارات وشاشة مصادر ومراجع.

## التشغيل من واجهة Android Studio

افتح مجلد `android-app` في Android Studio، ثم اختر جهازاً افتراضياً أو جهاز Android متصلاً واضغط **Run** لتثبيت نسخة debug وتشغيلها. لا يحتاج التطبيق إلى خادم أو حساب أو مفتاح API؛ البيانات المحلية موجودة في `android-app/app/src/main/assets/data/catalog.json`.

## الأوامر المهيأة

جميع الأوامر تعمل من جذر المستودع، ولا تبدأ تلقائياً أثناء الإعداد.

| الغرض | الأمر |
| --- | --- |
| تثبيت/تحضير الاعتماديات | `make install` |
| التطوير وتثبيت نسخة debug على جهاز Android | `make dev` |
| المعاينة نفسها على جهاز Android متصل | `make preview` |
| بناء APK debug | `make build` |

يمكن تنفيذ الأوامر مباشرة من مجلد `android-app` باستخدام `./gradlew dependencies` و`./gradlew installDebug` و`./gradlew assembleDebug` على الترتيب. يتطلب ذلك **JDK 17 أو أحدث** وAndroid SDK مثبتاً مع Android Studio، بينما يحمّل Gradle Wrapper نسخة Gradle المحددة في المشروع.

## متطلبات البيئة

لا توجد متغيرات بيئية مطلوبة لتشغيل نسخة debug ولا ملفات `.env`. يجب أن تكون `JAVA_HOME` مضبوطة على JDK صالح، وأن يكون `ANDROID_SDK_ROOT` أو إعداد SDK داخل Android Studio متاحاً عند البناء أو التثبيت على جهاز. ولتوقيع نسخة release بمفتاح مخصص يمكن اختيارياً ضبط `KEYSTORE_PATH` و`STORE_PASSWORD` و`KEY_ALIAS` و`KEY_PASSWORD`؛ وإذا لم تُضبط، يستخدم إعداد المشروع مفتاح debug المولد تلقائياً.

## الأصول البصرية

تم استبدال الصور القديمة بمجموعة موارد منظمة تحت `android-app/app/src/main/res/drawable-nodpi/`. لكل قسم خلفية مستقلة باسم `section_*_background.png` ورسم شفاف مستقل باسم `section_*_illustration.png`، ويمكن استبدالهما لاحقاً دون تغيير منطق البيانات. يحدد `catalog.json` صورة كل عنصر بحسب القسم، بينما تعرض الصفحة الرئيسية الخلفية والرسم المرتبطين بالقسم المختار.

## ملاحظات التصميم

تم توحيد مقياس الخط العربي في `ui/theme/Type.kt`، وتقليل تضخم العناوين، وضبط تباعد الأسطر. كما تم تخفيف حركة الانحناء في شريط التنقل السفلي إلى انتقال زمني ناعم دون ارتداد مبالغ فيه، مع تقليل تكبير ورفع الأيقونة النشطة. عناوين التنقل قصيرة وواضحة: **خريطة مصر، المفضلة، الرئيسية، الاختبارات، المزيد**.
